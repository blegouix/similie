Detailed Description

template<class X, class Y, class Z>
class similie::physics::magnetostatics::MagneticFormResponse< X, Y, Z >

Isotropic magnetic response H = nu(|B|_g) star_g B in three dimensions.

Important
This operator and documentation is fully AI-generated. B contains differential 2-form coefficients (B_yz, B_zx, B_xy), and the output contains 1-form coefficients (H_x, H_y, H_z). No cochain measures enter this operator. The metric and orientation belong to the continuous Hodge star; callers separately reconstruct and reduce their cochains.

The supplied equations describe the material energy in an orthonormal frame. Evaluating them along (|B|_g,0,0) provides the radial material law. The metric is Riemannian and the coordinate orientation is positive. This applies to isotropic materials only. The tangent differentiates the same metric norm and Hodge map as the field, including off-diagonal terms.
