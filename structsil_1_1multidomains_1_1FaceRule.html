template<class Dimension, class Field>
struct sil::multidomains::FaceRule< Dimension, Field >

A runtime face policy with the same sampling API as an individual rule.

Important
This operator and documentation is fully AI-generated. Only this face's donor view and mapping are captured in kernels, never the host adjacency vectors. Runtime flags also guide geometric truncation and Dirichlet assembly. The caller retains ownership of the donor allocation.
