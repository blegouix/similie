Detailed Description

template<class Operator, class Index, class First, class Second, class Target, std::size_t FirstRadius, std::size_t SecondRadius, class Domain, class Memory, class Exec = typename Memory::execution_space>
class sil::exterior::BilinearSpatialOperatorStorage< Operator, Index, First, Second, Target, FirstRadius, SecondRadius, Domain, Memory, Exec >

Cache a bilinear spatial map without freezing either operand.

Operator::value(geometry, first, second, element, arguments...) returns a BilinearStencil. Input fields supply domains and types, not frozen values. As for linear spatial staging, point indices use periodic addressing; value() must fold other homogeneous boundary rules into the coefficients. Output must not alias either operand. Rebuild after geometry or rules change.
