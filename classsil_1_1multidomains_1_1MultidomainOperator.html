Detailed Description

template<class Operator>
class sil::multidomains::MultidomainOperator< Operator >

Dispatch any homogeneous collection of domain operators.

Important
This operator and documentation is fully AI-generated. Each entry retains its ordinary operator/value API. Batch application gives each domain a partitioned execution space and fences before releasing those spaces. value(id, ...) forwards to the selected operator; operator[](id) provides a copyable local operator for pointwise evaluation in kernels.
