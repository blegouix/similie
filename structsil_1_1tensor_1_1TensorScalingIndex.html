Detailed Description

template<TensorNatIndex... TensorIndex>
struct sil::tensor::TensorScalingIndex< TensorIndex >

Store a scalar multiple of the identity using one coefficient.

For a matrix, this represents \(A_{ij} = \alpha\delta_{ij}\): every diagonal entry equals the stored value, and every off-diagonal entry is zero. All index dimensions must have the same size. For higher ranks, an entry equals the stored value when all its natural indices agree, and zero otherwise.
