Detailed Description

template<std::size_t N, class Data>
class sil::multidomains::Multidomain< N, Data >

Bind homogeneous field/geometry/physics views to a runtime topology.

Important
This operator and documentation is fully AI-generated. Domain count is unrestricted. The topology owns exterior policies; physical data owns views, not mesh allocations. Returned ExtrapolationRules retain the usual per-dimension pairs and normalized outward-distance corner blend. Thin donor references point into host/device-accessible arrays owned by this binding. Keep the binding, source bindings of transformed data, and cochain allocations alive until submitted work finishes. SharedSpace holds metadata only; the cochain allocations retain their original memory space.
